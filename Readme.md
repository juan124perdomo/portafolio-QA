# Portafolio QA & Análisis Funcional — Juan Felipe Perdomo

Portafolio de aseguramiento de calidad (QA) y análisis funcional de software.
Tecnólogo en Análisis y Desarrollo de Software (SENA).

Todos los artefactos están construidos sobre la aplicación pública de práctica
**SauceDemo** (https://www.saucedemo.com), aplicando técnicas formales de diseño
de pruebas y análisis de requisitos.

## Contenido

El portafolio sigue el **ciclo de vida de QA**, en orden:

- **01 · Análisis funcional** — historias de usuario (HU) con criterios de aceptación en Gherkin, organizadas por módulo. Definen el comportamiento esperado.
- **02 · Plan de pruebas** — objetivo, alcance, estrategia, tipos de prueba, criterios de entrada/salida y ambientes.
- **03 · Módulos probados** — por cada módulo: matriz de casos de prueba (positivos, negativos y de borde, trazados a las HU) y evidencias de ejecución con reportes de defectos.

**Módulos:** Login · Tienda

## Habilidades demostradas

Pruebas funcionales · Diseño de casos de prueba · Casos borde y negativos ·
